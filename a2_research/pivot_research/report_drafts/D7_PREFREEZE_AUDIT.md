# D7 pre-freeze audit

**Scope:** hostile, read-only review of `specs/r4_prereg/D7.md`. No outcome prices, returns, signals, or D7 results were accessed or computed; `LINKS.csv` was not opened. Findings below identify specification issues and exact proposed replacements before freeze.

## Findings and proposed replacements

| Priority | Finding | Exact replacement text |
|---|---|---|
| **BLOCKER** | **The event clock is not fully executable at the market boundary.** “First complete regular NYSE session … strictly after any known public timestamp” is conceptually conservative, but does not define timezone, open/close boundary, how date-only timestamps are treated, or what happens when the release is disseminated during a session. “First complete session” could mean a full session after the release or merely the first session that has completed since it. That ambiguity can move the response session and leak part of a same-day reaction into the event shock. | “Normalize EDGAR acceptance and explicitly stated release timestamps to America/New_York. Let `a` be the first NYSE session whose 09:30 ET open is strictly later than the later known timestamp; a timestamp exactly at 09:30 ET is treated as not earlier than that open, so use the following session. Let `f` be the first NYSE session strictly after the filing date. The response session `d` is the later of `a` and `f`. If no explicit release timestamp is available, treat the filing-date anchor as date-only and set `d=f`. If an explicit release time is during regular trading, use the next session. Record the normalized timestamps, `f`, `a`, and final `d` for every event. Compute the customer shock only on `d` after that entire session has completed.” |
| **BLOCKER** | **The SPY benchmark conflicts with the stated price-universe restriction and is not sourced.** D7 authorizes point-in-time Dow daily prices and says not to use non-Dow prices, but the primary signal requires SPY adjusted closes. The input source, coverage dates, corporate-action convention, missing-date handling, and whether SPY is an explicit exception are not fixed. In addition, subtracting SPY return is a market-adjusted excess return, not a beta-adjusted abnormal return; the label overstates the adjustment. | “The sole market adjustment is the one-session SPY excess return using the existing `oos3/xasset` SPY adjusted-close series, with the same calendar and adjustment convention documented in the input manifest. SPY is the only non-Dow price series permitted for D7 and is used only as a benchmark; do not download or substitute another benchmark. If a customer or SPY adjusted close is missing on `d` or `d−1`, exclude that event date under the fixed missing-input rule and report the count. Define `u[c,d]` as the customer’s SPY-excess close-to-close return, not as a beta-adjusted abnormal return.” |
| **BLOCKER** | **The file does not establish that the numeric feasibility gate was set before anyone inspected the link-panel counts.** Its text fixes the thresholds before outcomes, but that is not the requested pre-`LINKS.csv` chronology: the gate depends directly on the event and edge breadth in an L1-built file and can otherwise be tuned to observed coverage. I did not inspect `LINKS.csv`, so this chronology cannot be verified from the preregistration alone. | “The following input-only thresholds were fixed before the D7 authors or decision-makers viewed `LINKS.csv`, its row counts, coverage summaries, or any D7 outcomes: 30 eligible event-response dates, 10 directed pairs, and 80% shuffle coverage. Record the dated, content-hashed D7 text and the L1 handoff date in the freeze log before L1 provides the file or any coverage summary. If anyone has already inspected LINK-panel counts, disclose that fact and do not describe this gate as pre-inspection; keep D7 infeasible unless the same thresholds can be justified from an independently dated rule not chosen using those counts. Do not view the file to decide whether to retain or change these thresholds.” |
| **SHOULD-FIX** | **The placebo gates do not establish “no effect,” and the within-industry permutation is under-specified.** An absolute Newey–West `|t|<2` is failure to reject zero, not evidence that the placebo effect is negligible. The shuffling description does not define a complete draw when constraints make a customer’s requested number of alternate suppliers impossible, and the 80% feasibility threshold leaves up to 20% of dates without placebo assignments without fixing whether those dates are removed from the observed comparison. These choices can change the null and sample. | “Use the exact same eligible event dates for observed and all placebo comparisons; if a date cannot be shuffled, D7 fails the input gate rather than dropping that date from only one side. For each draw, jointly permute supplier endpoints within the observed supplier’s point-in-time two-digit SIC, preserving each customer’s number of edges and supplier SIC counts, with no self-edge, duplicate edge, or reuse of a supplier endpoint within that customer’s draw. Generate 500 valid complete network draws with the registered seed; if any draw cannot be completed, mark the placebo infeasible and do not substitute a different pool. For both the mean shuffled IC series and the time-shift placebo mean IC, report a 90% Newey–West confidence interval and run a two one-sided equivalence test against the fixed materiality band [−0.0183, +0.0183]; a placebo passes only if the full interval lies inside that band. The `|t|<2` statistic may be reported as a descriptive diagnostic, not as proof of no effect. For the timing placebo, keep each event’s original response-date link set fixed and shift only the shock date by exactly 20 sessions, so newly disclosed links cannot enter the placebo.” |
| **SHOULD-FIX** | **The enumerated Holm list is incomplete for the stated placebo gates.** The four D7 endpoints omit the average shuffled-series NW test, while the shifted-placebo endpoint is a two-sided test of zero even though passage is framed as equivalence/no effect. If the suggested equivalence tests are adopted, they are additional goal tests. The “full family” therefore cannot remain 25 as currently stated. | “Keep all 21 existing D4–D6 endpoints. Add these six D7 endpoints to the goal-wide Holm family: (1) primary event-date mean supplier rank IC, one-sided Newey–West test; (2) observed mean IC versus within-industry shuffled-link means, one-sided finite-sample randomization test; (3) mean shuffled-link placebo IC equivalence to zero within ±0.0183, two one-sided Newey–West test; (4) 20-session timing-placebo mean IC equivalence to zero within ±0.0183, two one-sided Newey–West test; (5) portfolio net excess return versus EW30, one-sided block-bootstrap test; (6) any other inferential endpoint added before the freeze, listed explicitly here. The family has 27 endpoints if no other endpoint is added. Report raw and Holm-adjusted p-values for every endpoint that is run, and retain every registered but not-run endpoint in the manifest. The two equivalence endpoints replace the current claim that `|NW t|<2` proves a null effect.” |
| **SHOULD-FIX** | **The five-session horizon is not the horizon directly supported by the cited customer–supplier papers.** Cohen and Frazzini’s primary customer-momentum design uses lagged one-month customer returns and monthly portfolio returns; their event-time figure describes subsequent monthly drift, including a six-month cumulative-return window. Menzly and Ozbas report cross-predictability across economically related supplier/customer industries, but the accessible journal abstract does not establish a five-session earnings-event horizon. Thus five sessions can be a deliberate short-horizon extrapolation, but must not be presented as an established horizon from these citations. | “The five-session outcome is a fixed, short-horizon extrapolation chosen for this project; it is not the horizon established by the cited papers. Cohen and Frazzini (2008) use monthly customer-return sorts and report subsequent monthly supplier drift, including a six-month cumulative-return analysis ([Journal of Finance DOI](https://doi.org/10.1111/j.1540-6261.2008.01379.x); [author-hosted full text](https://pages.stern.nyu.edu/~afrazzin/pdf/Economic%20Links%20and%20Predictable%20Returns%20-%20Cohen%20and%20Frazzini.pdf)). Menzly and Ozbas (2010) motivate gradual information diffusion across supplier/customer industries, but do not validate this event-level five-session specification ([Journal of Finance DOI](https://doi.org/10.1111/j.1540-6261.2010.01578.x)). Keep the five-session horizon fixed if D7 is intended as a distinct short-horizon test; do not describe it as a directly replicated literature horizon or change it after results.” |
| **SHOULD-FIX** | **Thesis fit is limited.** The design predicts supplier returns from customers’ earnings-related price moves. It measures information diffusion through a real-economy network, not buying pressure, signed order flow, or persistence of a pressure signal. D7 itself correctly says it does not identify non-informational order flow or causal transmission; its result should therefore be treated as an adjacent information-diffusion test, not direct confirmation of Advik’s buying-pressure mechanism. | “D7 tests whether earnings-news price responses diffuse across publicly disclosed customer–supplier links. It is an adjacent information-diffusion test and does not directly measure buying pressure, order flow, or causal transmission. A positive D7 result supports the broader network-spread motivation only; it does not establish the buying-pressure mechanism in Advik’s thesis.” |
| **NOTE** | **The draft already locks one primary variant and the event measure.** It expressly disallows CLV substitution, alternative benchmarks, alternate event categories, or other horizons as rescue variants. Preserve that restriction while clarifying the timestamp and benchmark inputs above. | “No second event, benchmark, or horizon may be introduced after freezing; any such change requires a newly logged variant and available trial-budget capacity before outcomes.” |

## Overall assessment

D7 is not ready to freeze. The core question is coherent and the SEC named-link requirement is a meaningful network definition, but the event clock and SPY input source need executable, auditable rules. Most critically, a fixed before-outcome gate is not necessarily fixed before link coverage was inspected; D7 must establish that chronology without opening `LINKS.csv`. The literature supports customer–supplier information diffusion, but the cited Cohen–Frazzini analysis uses monthly returns and documents drift well beyond five sessions, so D7’s horizon must be called a project-specific short-horizon extrapolation. Finally, the current “`|t|<2`” placebo wording cannot establish absence of an economically meaningful effect, and the Holm family omits placebo inference checks. No D7 outcomes were accessed or computed in this audit.
