# R6 screened-idea index

Metadata index of the R6 idea-screen documents and the seven frozen directions. Screen rows summarize each screen artifact; where a file bundles related candidates, the mechanism cell names the bundle and tags identify its components. This index contains no outcomes. Frozen entries are separate from their originating screen files so prior screening and frozen specifications remain grep-distinguishable.

Tags use lowercase, space-separated `tag:value` tokens for simple `rg` overlap checks. “Main kill reason” is the screen's documented gate-level reason; frozen items are marked as not killed here. The source cell names the principal proposed/input source, not a claim that coverage passed.
