# D4 — Common-owner CLV pressure on a dated 13F network

**Status: NOT FROZEN — ready for coordinator freeze after input checks.** This is a pre-registration; it contains no D4 outcome results. The coordinator freezes it only after checking the input files and before computing any D4 signal/return statistic, adding `FROZEN: YYYY-MM-DD` and a SHA-256 hash.

## Hypothesis and prediction

Positive five-session close-location pressure in Dow stocks connected by a common institutional owner predicts positive next-week returns in those connected stocks. The proposed channel is persistent or spreading buying pressure transmitted through common ownership. Daily OHLCV CLV is only a price-location proxy; it is not signed order flow. The primary prediction is a positive date-wise Spearman rank IC between the network-pressure score at close t and each stock's next-open-to-close return from t+1 open through t+5 close. The primary mechanism gate is mean IC > 0 with Newey–West Bartlett t ≥ 2.00, using lag 4 across dates.

## Primary test and fixed placebos

For each date, calculate Spearman correlation across eligible point-in-time Dow names between NCP and `adjusted_close[t+5] / adjusted_open[t+1] − 1`. Report the date-wise series, mean IC, number of dates, and Newey–West t-statistic with Bartlett lag 4. The positive-sign and t ≥ 2.00 gate must pass on variant 1. This is a predictive mechanism test, not causal identification.

Use these pre-fixed placebo checks with one NumPy `default_rng(20261110)` generator, consuming draws in the listed family order, 500 draws per randomized family: (1) for each dated directed graph, attempt exactly 10×E double-edge swaps, preserving every node's in- and out-degree; skip any swap that creates a self-edge or duplicate edge, then reassign the original edge-weight multiset in a random order; (2) independently place the same number of directed non-self edges uniformly without replacement and randomly assign the observed edge-weight multiset; and (3) pair each signal date t with the graph from exactly 20 trading sessions earlier, wrapping the dated graph sequence circularly. After each rewiring, preserve zero rows and row-normalize every nonzero row to sum to one. Report the observed IC, all 500 placebo statistics per randomized family, and one-sided randomization p-value `(1 + count(placebo_statistic >= observed_statistic))/(500 + 1)` for each. The observed IC must exceed the 95th percentile of each placebo distribution and each randomization p-value must be < 0.05; use NumPy's linear percentile definition for these percentile checks.

To test that the placebo effects are practically negligible (rather than merely failing to reject zero), for each randomized family average the 500 draw-specific date-wise IC series date-by-date, then calculate that average series' mean and two-sided 90% Newey–West confidence interval with Bartlett lag 4. Require the entire interval to lie within [−0.00577, +0.00577], which is equivalent to passing two one-sided equivalence tests at 5%; report the larger of the two one-sided p-values as the family equivalence p-value. Also require the 95th percentile of the absolute draw-specific mean ICs to be below 0.00577, using NumPy's linear percentile definition. Report all intervals, percentile values, and p-values. The 0.00577 equivalence margin is the cap-based cost-only reference defined below; it is not the conservative advancement hurdle. The 20-session shifted placebo uses its same date alignment for the observed comparison and placebo statistic. A failed primary mechanism or placebo gate ends D4; variants 2–3 cannot rescue it.

## Evidence basis and limits

Common ownership can connect stock returns and transmit trading demand, but the cited evidence does not establish that daily OHLCV CLV propagates across Dow stocks through quarterly 13F links. CLV is not signed order flow; 13F holdings are delayed snapshots, omit short positions, and may leave the graph stale between filings. The proposal therefore tests one narrow, falsifiable mechanism rather than assuming it works.
