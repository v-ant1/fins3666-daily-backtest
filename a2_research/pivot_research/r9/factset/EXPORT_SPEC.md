# FactSet export for the R9 point-in-time panel

## Export once, in FactSet Workstation

1. Open **FactSet Screening** (Universal Screening), choose **Historical Constituents**, index `SPX` (S&P 500), and request membership effective dates **2009-01-01 through 2020-10-30**, including inactive securities, deleted/delisted members, and all historical security lineages. Repeat for `DOW` (Dow Jones Industrial Average) so the Dow panel can be derived as an index subset. Export security-level records, not issuer-only records.
2. Add these FactSet fields: FactSet entity ID and security ID; historical ticker and ticker effective start/end; CUSIP, ISIN, CIK (when available); index code, membership start/end; daily date, open, high, low, close, volume; split and dividend adjustment factors **or** adjusted open/high/low/close; SIC and GICS code with effective-from/effective-to dates (include SEC acceptance date if supplied); delisting date, reason and delisting return when available. Request the full daily history **2010-01-01 through 2020-10-30** for every constituent identity, including inactive ones. Preserve the export's original identifiers and date fields.
3. In FactSet Excel add-in, use the FactSet Screening export workbook and historical price series functions (FDS codes for the fields above). Excel worksheets are limited to 1,048,576 rows. Batch by calendar year and/or security-ID ranges, repeat headers in every batch, and save every batch; use Screening's CSV export for daily prices if the requested history exceeds a worksheet. Do not drop inactive names when batching.
4. Save UTF-8 CSVs under `pivot_research/factset_raw/` with exactly these names: `membership.csv` (`index_code,entity_id,security_id,ticker,ticker_start,ticker_end,membership_start,membership_end`); `security_master.csv` (`security_id,entity_id,ticker,ticker_start,ticker_end,cusip,isin,cik`); `daily_prices.csv` (`security_id,date,open,high,low,close,volume,split_factor,dividend_factor,adjusted_open,adjusted_close`); `classifications.csv` (`security_id,sic,sic_effective_start,sic_effective_end,gics,gics_effective_start,gics_effective_end,sec_acceptance_date`); `delistings.csv` (`security_id,delisting_date,delisting_reason,delisting_return`). Leave unavailable values blank. If exporting adjusted prices instead of factors, include adjusted open and close and leave factors blank. Do not rename the headers.

`membership.csv` includes both index codes; the Dow arrays are produced by selecting its `DOW` rows, while the S&P arrays use `SPX`. Keep the source extracts unchanged in `factset_raw/`; the builder writes the derived NPZ separately. No FactSet extract is present yet.
