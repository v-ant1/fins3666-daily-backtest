# E1 frozen runner specification map

`run_e1.py` implements the frozen `specs/r6_prereg/E1.md`. The runner reads the prepared monthly signal bundle and the published input-only manifest; adjusted development OHLCV is loaded only inside the guarded execution function, after `--execute` and after the input gate passes. It does not download data, access holdout files, write into the preregistration, or execute by default.

## Frozen rules to implementation

| Frozen E1 rule | Runner implementation |
|---|---|
| Frozen digest and execution lock | `@guarded_runner(PREREG, RUN_DIR)` calls `validate_frozen_prereg`, requires explicit `execute=True` or `--execute`, prevents a second run artifact, and retains its run lock after execution/failure. `--check-freeze` only verifies the hash. |
| Signal-only prepared inputs | `E1_INPUTS.npz` has monthly formation dates, stock pressure, leave-one-out peer pressure, active roster/pressure/SIC/peer masks, SIC2 labels, group sizes and peer counts. `validate_bundle` validates shapes, date order, and masks without calculating outcomes. |
| Input QA gate | `coverage_gate` checks development-only flags, S&P and Dow OHLCV-plus-SIC member-day coverage ≥90%, and ≥80% of S&P dates with ≥250 eligible peer scores. It reports 51 unresolved historical ticker price series. Failure occurs before loading the NPZ or any forward price series. |
| SIC2 score and point-in-time membership | The frozen bundle's dated SIC2 labels, membership masks and leave-one-out scores are consumed as built; no broadening or reassignment is done for the observed test. Stocks lacking price data on an outcome date produce missing returns and are excluded on that date. |
| Calendar and 21-session primary outcome | The runner loads the development-only adjusted SP500 OHLCV panel and forms each return from next-session adjusted open through the close of the 21st following session, using `open * adj_close / raw_close`. The last formation is omitted by a trading-calendar-only 21-session eligibility mask. `r4_harness.ic_engine.cross_sectional_ic` computes date-wise Spearman IC; `newey_west_t` uses Bartlett lag 20. R6-H4 requires mean IC ≥0.001155 and NW t ≥2; the one-sided normal-tail p is reported. |
| SIC2-preserving placebo | `shuffle_sic2_labels` permutes mapped SIC2 labels within each date over the frozen mapped roster, preserving the exact group-size multiset. `_peer_score_from_labels` rebuilds leave-one-out peers from fixed stock pressure. The runner uses 500 draws and seed 20261111. R6-H5 requires observed mean IC above the shuffled mean-IC 95th percentile and one-sided `(1 + #null>=observed)/501 <0.05`. |
| Dow monthly top-five strategy | At the next session's open after each formation, select the five highest frozen peer-pressure scores among roster names with available execution prices. Starting from point-in-time EW30, `_capped_step` takes the largest pro-rata step with buys plus sells / NAV ≤20% per rebalance, including the initial transition. If fewer than five names have valid scores/prices, the date is disclosed as a selection failure and the portfolio gate fails. |
| Costs, EW30, active share and portfolio gates | Charge 0.0005 per dollar of total traded notional. Daily strategy and point-in-time EW30 returns use the same date-wise available members. The runner reports eligible-name counts per formation, average/max turnover, cap-binding dates, daily average active share, cumulative gross/net returns, Sharpe, maximum drawdown, costs and cost/gross-edge ratio. E1 requires positive net excess return, net Sharpe above EW30, active share ≥50%, and actual turnover ≤50%; its 20% cap satisfies the registered turnover-or-cost criterion. |
| Circular block bootstrap | `r4_harness.phase3.circular_block_bootstrap_pvalue` tests net excess returns using circular 10-session blocks, 5,000 draws, seed 20261111. Raw and full-family Holm adjusted p-values are reported. |
| Holm family and endpoint rows | Existing D1 R6-H1..H3 p-values are read from its endpoint log only during authorized execution. E1 appends one row each for R6-H4 (mechanism), R6-H5 (SIC2 placebo), and R6-H6 (Dow net excess). If an earlier gate blocks H6, its endpoint row is `not run` with no raw p-value; a conservative p=1 is used internally for the Holm slot. Holm is computed over H1..H6 only, with R6-H6 passing only if its Holm p<0.05. |
| DSR trial count | `_r6_trial_count` counts unique `R6 variant n: NAME` entries in the R6 section of `specs/r4_trials.md`. DSR counts unique strategy variants, not endpoints, placebo draws, or bootstrap draws. |
| Development and holdout boundary | Price loaders filter to 2020-06-01 through 2026-10-30 before matrix creation; SIC history is consumed only through the frozen development bundle. No holdout path is defined or loaded. |

## Run controls and outputs

Running `python -m r6_E1.run_e1` prints a no-outcomes notice. `python -m r6_E1.run_e1 --check-freeze` validates only the frozen preregistration digest. The explicit `--execute` switch is required to read the NPZ and price panels and to write `r6_E1/run/E1_RESULTS.json` and `E1_ENDPOINTS.csv`.

`PREREG_DIFF.txt` records the numeric audit from `r4_harness.prereg_diff`. Numeric normalization is in memory only: it removes thousands separators, makes the explicitly registered 21-session horizon and one variant machine-readable, and omits synthetic power-planning assumptions from runtime parameter extraction. It does not change the frozen file or its hash.
