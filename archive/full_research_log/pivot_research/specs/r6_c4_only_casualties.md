# R6 criterion-4-only casualties

## Verdict

**No idea qualifies.** After reading all 38 `r6_ideas/*.md` files, I found no non-excluded direction whose only documented failure is criterion 4 or top-five cost feasibility while its thesis fit, literature, data, novelty, and power gates otherwise pass. The set to rank is therefore empty; I have not promoted any “near miss” into the requested category.

The screen is intentionally strict: a conditional/assumed data pass is not a pass; “power is adequate only if an unsupported large effect is assumed” is a power failure; and a reported paper return spread is not a substitute for a matched pressure signal, large-cap effect, or rank IC. I excluded the frozen-and-run D1, E1, J1, R1, P1, K1, G1, D4–D7 families as directed. This is an audit of the idea-screen documentation and published literature estimates only; it uses no project signal outcomes, returns, portfolio results, or holdout data.

## Audit rule and result

An idea would appear in the requested list only if its screen documented all of the following: (1) a thesis-consistent pressure mechanism and adequate verified literature; (2) a credible large-cap/post-2020 case; (3) a passed, design-matched power gate; (4) criterion-4 or top-five cost feasibility as the sole failed gate; (5) usable free/staged point-in-time data; and (6) novelty relative to R5 and other R6 ideas. I found no remaining idea satisfying items 1–3, 5, and 6 while failing only item 4. In particular, the larger numerical effects above each fail independent requirements, so moving them into a cost-only list would overstate the evidence.

**Ranked C4-only list: empty.** No additional variant is justified by this audit.
