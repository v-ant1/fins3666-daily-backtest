# FactSet fields for S2 candidates

**Tag: L-S2F.** No candidate passed the outcome-free evidence/power gate, so this is an export-field checklist for any bounded reconsideration, not authorization to compute signals. Export with permanent security ID, historical ticker, exchange, currency, active/inactive status, effective-from/to dates, and source/as-of timestamps. Include inactive/delisted securities and delisting/corporate-action type and return; do not map history only through current tickers.

| Candidate | Extra fields beyond the common PIT security master and daily adjusted OHLCV | Timing / point-in-time requirement |
|---|---|---|
| Index additions/deletions | S&P 500 membership change history: announcement timestamp, effective date, add/delete flag, old/new index weight if available | Preserve original publication timestamp and effective date; distinguish announcement from implementation. |
| Analyst revisions | IBES/FactSet analyst identifier, broker, recommendation scale, prior/current recommendation, action type, action timestamp/time zone; analyst EPS/revenue forecasts, fiscal period, prior/current values, estimate timestamp, actual announcement timestamp, currency/unit | Full vintage history, not latest consensus; first usable session strictly after vendor publication/availability timestamp; retain withdrawn/cancelled actions. |
| Days-to-cover / short interest | Settlement-date short interest / shares short, publication timestamp, exchange/venue coverage, split-adjusted shares outstanding, point-in-time shares float (if a float-normalized variant is considered); daily dollar-volume denominator is derived from adjusted OHLCV | Use first tradable session after public/vendor release; preserve settlement and release dates separately. No look-ahead to revised vendor histories. |
| Industry momentum | Effective-dated SIC/NAICS/GICS code with classification system, source timestamp, issuer/security lineage and change history | Classification only from first eligible session after source acceptance/publication; no current-code backfill. |
| 52-week high | No FactSet-specific extra field beyond adjusted daily OHLCV and corporate-action factors | Split/dividend adjustment basis and correction/vintage timestamps must be documented. |
| Offerings / lockups | Offering type, filing/announcement timestamp, pricing/issuance date, shares offered, lockup end date, security link, event source/status | Preserve filing vintages and amendments; distinguish registration, pricing, and unlock dates. |
| Dividend ex-date | Ex-date, amount, currency, declaration/announcement timestamp, payment date, event status and adjustment factor | Use announced event vintage; total-return adjustment must not count the mechanical dividend price drop as alpha. |
| Quarter/month-end; ETF flows | FactSet fund identifier, creation/redemption shares or flow, timestamp, fund holdings/security weights by effective date, rebalance/cash-flow constraints if licensed | Point-in-time creation/redemption and holdings vintages; security-level attributed flow must not be inferred from broad calendar dates. |
| PEAD / overnight / abnormal volume | PEAD: point-in-time consensus EPS and actual EPS with fiscal period and announcement timestamps. Overnight: adjusted open/close and corporate-action factors. Volume: split-adjusted volume, correction timestamps | Consensus must be archived as known before the announcement; open/close timestamps and volume adjustments must be consistent across inactive securities. |

A later prereg must request only the fields for its selected signal and name the vendor dataset/entitlement, historical start date, update/vintage behavior, and security-link key. The assumed base export already supplies PIT S&P membership, daily adjusted OHLCV, inactive securities, and classified delisting returns.
